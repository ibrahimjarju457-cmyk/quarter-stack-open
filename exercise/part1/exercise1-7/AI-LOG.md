# AI Log: Documented Page Project

This log records how an AI assistant (Claude, made by Anthropic) was used on this project, what it produced, and what was checked afterwards and what was changed.

## Project summary

- **Assignment:** Build a documented HTML page for a real audience, with at least three sections, a mix of paragraphs and lists, correct heading hierarchy, section-marking comments, explanatory comments, at least one specific `<!-- TODO: … -->`, Prettier indentation, and zero.
- **Result:** a study guide, "HTML Structure Study Guide", for classmates in an Intro to Web Development class.
- **Files:**
  - `documented-page.html`: the page structure and comments
  - `styles.css`: the styling, split out in the second step
  - `AI-LOG.md`: this file

## Interaction log

### 1. Initial build

- **Prompt (summarised):** Build a page for a real audience following the assignment requirements, saved as `documented-page.html`.
- **What the AI did:**
  - Chose the topic itself: a study guide on HTML structure. It chose a topic that needed no facts about a real place or organisation, so nothing could be invented.
  - Wrote the full page: four `<h2>` sections with `<h3>` subsections, a `<ul>`, two `<ol>` lists and a `<dl>`, a skip link, a table-of-contents `<nav>`, and landmark elements.
  - Added banner comments for each section, comments explaining non-obvious choices (skip link placement, `aria-labelledby` on sections, `aria-label` on the nav, why a `<dl>` was used), and one TODO about adding practice snippets and an answers list once the instructor posts the quiz topics.
  - Ran Prettier 3 over the file and checked it with `html-validate`.
- **Result of checking:** `html-validate` reported 3 style-rule complaints and no structural errors: the lowercase `<!doctype html>`, and `/>` on two void `<meta>` elements. Prettier adds the `/>`, and the W3C validator accepts all three, so they were left as they were.

### 2. Separate HTML and CSS

- **Prompt:** "separate the html and css"
- **What the AI did:**
  - Moved the `<style>` block into `styles.css` and added `<link rel="stylesheet" href="styles.css" />` to the head, with a comment explaining the split.
  - Reorganised the CSS under banner comments and added a comment explaining the off-screen skip-link technique.
  - Added a TODO in the CSS for a dark-mode `prefers-color-scheme` block.
  - Re-ran Prettier on both files and re-ran `html-validate`.
- **Result of checking:** the same style-rule complaints as before, plus the same `/>` complaint on the new `<link>` tag. No structural errors.
